# This pipeline is deliberately stdlib-only (see pipeline/common.py's own
# docstring) for everything except this one, narrow exception: NSE's own
# Report 1C (broker-wise active clients, UCCs and a defaulter flag for 263
# real trading members) is published only as a legacy binary .xls (BIFF/OLE2)
# file, which has no stdlib parsing path.
#
# xlrd 2.x specifically exists to read legacy .xls files - it dropped .xlsx
# support in 2020 to focus on exactly this narrower, more stable format, so
# it is the right tool for this one file, not a general-purpose dependency
# creeping in. Pure Python, no C extensions, pinned to an exact version.
#
# Install before running anything that imports pipeline.sources.nse_report1c
# (pipeline/run.py's "report1c" command): pip install -r pipeline/requirements.txt
#
# Kept out of the repo root on purpose: a root requirements.txt makes Vercel
# treat the whole project as Python, swap in its own uv-managed interpreter
# (CPython 3.14 on 3 Nov 2026, not the python3 every earlier build used) and
# mark it externally managed, so the pip install in scripts/vercel-build.sh
# failed every deploy. See that script for how the build installs this now.
xlrd==2.0.2
